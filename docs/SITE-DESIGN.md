# One product, four purposes

The previous site mixed an agent-focused homepage with an older invoice landing page, several overlapping demos, and a separate-looking contract lab. Navigation, page hierarchy, colors and controls differed across routes. The redesign gives each product page one purpose.

| Route | Purpose | Execution label |
|---|---|---|
| `/` | Inspect a payment proposed by the live model and its independent policy decision | Live inference + policy preview |
| `/desk.html` | Review invoices, persist reservations and reconcile recorded payments | Persistent synthetic accounting |
| `/lab.html` | Exercise the compiled treasury against altered reports and failed transfers | Local EVM |
| `/evidence.html` | Inspect model/CRE/contract records and separate Sepolia receipts | Recorded execution evidence |

The earlier batch and single-invoice examples remain accessible at `/examples.html` through technical references, with the shared navigation. They no longer duplicate the primary accounting workspace or appear as a second product landing page.

All pages use the same warm paper background, green accent, Manrope headings, DM Sans body text, restrained serif emphasis, border treatment, buttons, content width and footer. Shared header/footer markup is generated by `scripts/build-site.mjs`; it remains static HTML with native links, visible navigation on mobile and a keyboard skip link. CI checks generated markup to prevent drift.

The homepage shows a compact recorded-result summary with links to the evidence explorer. The evidence explorer renders the existing JSON artifacts directly, rather than manually maintaining another set of result claims. Accounting retains its existing storage key and controls, so saved workspaces survive the reorganization.

Visual consistency does not imply a fully connected execution pipeline. The agent preview, persistent accounting workflow, local EVM experiments and recorded CRE evidence remain accurately labeled. No backend, policy, contract or deployment-access behavior was changed by this redesign.

Validation: desktop, tablet and mobile route checks; all four navigation links visible; one page heading; active route labels; evidence rows and explorer links; no horizontal overflow; no broken internal anchors; existing live agent, accounting, reference-preview and contract-lab regression checks.
