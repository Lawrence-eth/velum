WHAT THIS PROVES — AND WHAT IT DOESN’T

A payment gate you can inspect.

Each experiment creates fresh local contracts, registers a complete five-invoice manifest, then submits the selected report. Every result is computed from EVM return values and token balances. No result is pre-recorded or selected from a success animation.

The local forwarder caller is simulated, so this does not verify Chainlink signatures or hardware attestation. Replay rejects the second report; the first report’s unspent approval remains valid for one payment. Transfer-failure testing preserves approval because the whole settlement reverts. These distinctions matter.
