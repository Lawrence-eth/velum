03 / UNDER THE SURFACE

Private terms.
Verifiable decisions.

Chainlink CRE’s confidential handler retrieves the work-order source and live GitHub evidence using separate credentials. It checks the accepted commit, repository, workflow definition and payment policy.

The ABI authorization omits raw commercial terms. The actual report drives Solidity settlement; saved reservations and execution history protect the work order across reloads.
